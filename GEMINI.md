# Project Overview

This is a client-side web application for creating and animating spirograph-inspired mathematical patterns. It is built with vanilla JavaScript, HTML, and CSS, and it uses the p5.js library for creative coding and animation.

The application is structured into three main files:
- `index.html`: The main HTML file that defines the structure of the user interface, including all the controls for customizing the patterns.
- `spiro.js`: This file contains the core logic of the application. It handles the animation, user interactions, and the mathematical calculations for generating the spirograph patterns.
- `style.css`: This file provides the styling for the application, including the layout, colors, and fonts.
- `themes.js`: This file contains a collection of preset themes that users can select from to quickly explore different patterns.

# Building and Running

This is a client-side application and does not require a build process. To run the application, simply open the `index.html` file in a modern web browser.

# Development Conventions

The code is written in a modular way, with a clear separation of concerns between the HTML, CSS, and JavaScript files. The JavaScript code is well-structured and uses functions to encapsulate different functionalities. The code is also well-commented, which makes it easy to understand.

The project uses a dark, modern UI, and the styling is defined in the `style.css` file. The application is designed to be interactive, with a set of controls that allow users to customize the patterns in real-time.
